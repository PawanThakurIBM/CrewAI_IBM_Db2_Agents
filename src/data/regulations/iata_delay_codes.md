# IATA Delay and Cancellation Codes — AHM730 Reference

**Document ID:** REG-IATA-730  
**Version:** Based on IATA Airport Handling Manual (AHM) 730, Edition 38  
**Owner:** Flight Operations / Quality  

---

## 1. Purpose

IATA AHM730 defines the standard delay codes used to classify the cause of flight delays and cancellations. Accurate coding is mandatory for regulatory reporting, performance analysis, insurance claims, and interline dispute resolution. All AirConnect delays must be coded within 2 hours of flight departure.

---

## 2. Code Structure

Codes are two-digit numbers (11–99) grouped into ranges by cause category. A sub-code (letters A–Z) further specifies the root cause within a category.

## 12. Key Coding Rules

1. **Primary code = dominant cause.** If multiple causes exist, use the code with the longest delay contribution.
2. **Code 91 (reactionary)** is only used when no other primary cause applies — it cannot be used to avoid accountability.
3. Codes 71–79 and 81–89 typically indicate extraordinary circumstances — compensation may not be due.
4. Codes 41–49 and 61–69 are typically airline-controlled — compensation applies.
5. Sub-codes must be used where applicable (e.g., 65A = FDP exceeded due to late inbound).
