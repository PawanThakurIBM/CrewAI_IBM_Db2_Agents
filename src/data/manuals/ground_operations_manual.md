# Ground Operations Manual — Disruption Procedures

**Document ID:** MAN-GND-001  
**Version:** 4.5  
**Effective Date:** 2024-01-15  
**Owner:** VP Ground Operations  

---

## 1. Purpose

This manual defines ground staff procedures during flight disruptions. It covers gate management, baggage handling, ground transport, vendor coordination, and DCS procedures specific to delay and cancellation events.

---

## 2. Gate Management During Delay

### 2.1 Gate Hold Procedure
When a delay is declared, the gate agent must:

1. Mark flight as delayed in DCS and update board/FIDS display within 5 minutes
2. Make initial PA within 10 minutes (use script from SOP-OPS-001)
3. Notify airport information desk to update arrivals/departures board
4. Ensure gate is held — do not release gate to another flight until ETD + 2 hours (or with Duty Manager approval)

### 2.2 Repeat Announcements
- Every 20–30 minutes for delays < 3 hours
- Every 15 minutes for delays > 3 hours (passengers become anxious)
- Immediately when ETD changes

### 2.3 Crowd Management
For delays > 2 hours:
- Set up secondary queue to avoid gate-area congestion
- Post visible signage directing passengers to service desk for rebooking
- Request additional security personnel if passenger frustration is elevated

## 3. Checked Baggage Handling During Cancellation

### 3.1 Bags Loaded on Aircraft
If bags are already in the hold when cancellation is declared:
- Do NOT offload without Duty Manager authorisation
- If flight is cancelled: offload all hold bags — this takes 45–90 minutes for a full aircraft
- Bags returned to baggage reclaim belt — advise passengers via PA and app notification
- Tag each bag with a disruption identifier for tracking

### 3.2 Bags at Check-in (Not Yet Loaded)
- Hold bags in secure area (not standard carousel)
- Issue a bag receipt slip to passengers
- Bags may follow on next rebooked flight or be collected by passenger at airport

### 3.3 Baggage Transfer to Rebooking Flight
- If passenger is rebooked same day: through-check bags to replacement flight when possible
- If airport DCS does not allow auto-transfer: print new bag tag, advise passenger
- For partner airline rebooking: interline bag transfer tag required

---

## 4. Ground Transportation for Passengers

### 4.1 Transport to Hotel During Overnight Disruption
- Arrange coach/bus transport — minimum 1 vehicle per 45 passengers
- Vehicle lead time from supplier: 45–60 minutes — order early
- Special vehicles required for WCHC passengers (advance booking mandatory)
- Provide hotel address and contact number in writing to all passengers

### 4.2 Transport to Alternate Airport
If passengers are transported by ground to an alternate airport for rebooked flight:
- Coach required, not public transport
- Estimated journey time must be communicated before passengers board
- AirConnect escort required on coach for groups > 20 passengers

---

## 5. Liaison with Catering, Fuel, and Cleaning Vendors

| Vendor | Action | Timing |
|--------|--------|--------|
| Catering | Update order time for delay; cancel for cancellation | Notify at T-90 min to ETD change |
| Fuel | Revised uplift plan from dispatch | Notify when delay exceeds 90 min |
| Cleaning | Reschedule if ground time changes | Notify when delay > 60 min confirmed |
| Ramp handling | Revised push-back schedule | Notify with updated ETD |

**Cancellation:** Cancel all vendor orders immediately after cancellation declaration. Late cancellation costs money and must be justified to finance.

---

## 6. Departure Control System (DCS) Procedures

### 6.1 Delay Entry
- Enter IATA delay code immediately when delay is identified
- Update ETD every 30 minutes or whenever information changes
- Log all passenger communications as remarks in PNR

### 6.2 Cancellation Processing in DCS
1. Change flight status to CANCELLED
2. Print cancellation manifests for rebooking team
3. Generate passenger contact list for automated notification
4. Close check-in — prevent new passengers from checking in
5. Generate refund authorisation codes for service desk agents

### 6.3 Rebooking Entry
For each rebooked passenger:
- Create new PNR or modify existing one
- Issue new boarding pass
- Update bag tags if baggage is transferring
- Record rebooking under original PNR for audit trail
