## 1. Purpose

This manual section covers airport-specific operational guidelines relevant to flight disruptions, including NOTAM interpretation, runway condition assessment, slot coordination, and remote parking procedures.

---

## 2. NOTAM Interpretation Guide

NOTAMs (Notice to Airmen/Airwomen) are official notices containing information about changes to aeronautical facilities, services, procedures, or hazards.

### 2.1 NOTAM Structure
A NOTAM contains:
- **Q-code:** Subject code and status (e.g., QRDCA = Runway declared closed)
- **A field:** Location (ICAO code)
- **B/C fields:** From/To times (UTC)
- **E field:** Plain language description

### 2.2 NOTAMs Most Relevant to Disruption Operations

| Q-Code | Meaning | Operational Impact |
|--------|---------|-------------------|
| QRDCA | Runway closed | Operations suspended or single-runway ops |
| QMRLC | Taxiway closed | Increased taxi times, possible delays |
| QPICH | ILS/Instrument approach unserviceable | CAT I only, may trigger diversion |
| QNVAS | Nav aid unserviceable | Alternate approach required |
| QLFLT | Lighting fault | Night ops restricted |
| QTCAH | Terminal area control active | ATC flow restrictions, ground stop possible |

### 2.3 NOTAM Validity Check
- Always check NOTAM validity window (B/C fields) against expected departure and arrival times
- A NOTAM valid at departure time may expire before arrival — check end time against ETA
- Pilots receive NOTAMs during briefing; Operations Controller cross-checks for active disruption relevance

## 3. Runway Condition Codes (RCAM)

Runway Condition Assessment Matrix (RCAM) codes are reported in ATIS and passed via SNOWTAM or METAR RMK.

| RWYCC | Surface Condition | Required Action |
|-------|------------------|-----------------|
| 6 | Dry | Normal operations |
| 5 | Wet (< 3mm water) | Normal operations, enhanced monitoring |
| 4 | Wet (> 3mm) / Slush | Performance adjustment per AMM |
| 3 | Dry snow, compacted snow | Performance adjustment, anti-skid confirmed |
| 2 | Wet snow, ice patches | Limited operations, assess per aircraft type |
| 1 | Ice, frost | Requires Captain's enhanced performance calculation |
| 0 | Wet ice | Operations PROHIBITED — declare suspension |

When RWYCC 0 is reported, NCC must immediately:
1. Halt all departures to/from affected airport
2. Notify all inbound flights via ACARS
3. Divert inbound flights to alternates if no improvement forecast within 60 minutes

## 4. Slot Coordination During Disruption

### 4.1 What Is a Slot?
At coordinated airports (Level 3 IATA), airlines must operate within a declared time slot. Missing a slot results in penalties and may cause the slot to be forfeited.

### 4.2 Slot Extension During Disruption
1. Operations Controller contacts Airport Slot Coordinator directly (via dedicated disruption line)
2. Request slot extension citing IATA delay code and estimated delay duration
3. Slot coordinator issues new CTOT (Calculated Take-Off Time) or advises available slot options
4. Accept earliest available slot that is operationally feasible

### 4.3 Slot Forfeiture Prevention
If departure is not possible within any offered slot today:
- Cancel the slot for today — do not hold it (penalty costs less than day-long hold)
- Request slot for next available time (same day or next day)

## 5. Remote Parking and Bussing Procedures

If allocated gate is not available (congested terminal, remote stand required):

### 5.1 Remote Stand Assignment
- Request from Airport Operations Centre (AOC)
- Confirm bus availability before committing to remote stand (minimum 2 buses per 150 passengers)
- WCHC passengers: ambulift or ramp vehicle required — confirm before disembarkation

### 5.2 Bus Manifest
Gate agent compiles bus manifest:
- Total passenger count
- Number of WCHR/WCHC passengers
- Number of UMs
- Number of infants (car seats required on bus)

### 5.3 Transfer Time
Standard remote stand to terminal: 8–15 minutes. Add 15 minutes for connection time calculation. Passengers with tight connections must be flagged for transfer priority.

## 6. Airport Emergency Plan Interface

During declared airport emergency:
1. AirConnect Station Manager reports to Airport Emergency Centre as airline liaison
2. All AirConnect communications routed through Station Manager — no direct media contact by gate agents
3. Crew and passengers follow Airport Emergency Plan instructions
4. AirConnect Crisis team activated — contacts Corporate Communications and Legal
5. Passenger information only released after authority clearance
